# REZON — برنامج التغذية والجيم

## ما الذي يعمل الآن؟
- واجهة عربية متجاوبة مناسبة للجوال.
- تسجيل الطعام يدويًا من قائمة أطعمة مع تقدير السعرات والبروتين والكربوهيدرات والدهون لكل كمية.
- رفع صورة وجبة ومعاينتها، وتسجيلها يدويًا كتقدير تقريبي.
- سجل يومي للوجبات، أهداف يومية قابلة للتعديل.
- جدول مقاومة لأربعة أيام مع تسجيل الأوزان والتكرارات والمجموعات.
- تسجيل الوزن ومحيط الخصر، ملخص آخر 7 أيام، والماء.
- حفظ البيانات محليًا في المتصفح، وتصدير نسخة احتياطية JSON.
- دعم PWA للتثبيت على أندرويد بعد الاستضافة على HTTPS.

## الصراحة بشأن تحليل الصور بالذكاء الاصطناعي
لا تحتوي هذه الحزمة على نموذج رؤية حاسوبي ولا مفتاح API. زر تحليل الصورة لن يتعرف إلى الطعام تلقائيًا حتى تهيئ خدمة تحليل خارجية. لا تضع مفتاح API سريًا في JavaScript أو داخل التطبيق.

### واجهة الخادم المطلوبة
في الإعدادات، أدخل عنوان HTTPS لخادمك. التطبيق يرسل `multipart/form-data` وفيه:
- `image`: ملف الصورة
- `grams`: كمية تقريبية كنص
- `meal_name`: اسم الوجبة/ملاحظات

يجب أن يعيد الخادم JSON مثل:
```json
{
  "name": "دجاج مشوي مع أرز",
  "grams": 350,
  "kcal": 520,
  "protein": 48,
  "carbs": 58,
  "fat": 9,
  "confidence": "متوسط"
}
```
هذا عقد تكامل مقترح، وليس خدمة جاهزة مضمّنة. الخادم يجب أن يستخدم مزود رؤية/ذكاء اصطناعي مع مفتاح مخزّن على الخادم، ويتعامل مع CORS، والخصوصية، وحدود الاستخدام. التقدير من صورة واحدة غير دقيق دائمًا؛ الوزن الفعلي والمكونات والزيوت والصلصات تؤثر كثيرًا.

## تثبيت على أندرويد
1. استضف محتويات هذا المجلد على استضافة HTTPS ثابتة (مثل GitHub Pages أو استضافة ويب موثوقة).
2. افتح رابط الموقع من Chrome على أندرويد.
3. من قائمة Chrome اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** إن ظهر الخيار.
4. افتح التطبيق من أيقونته.

فتح `index.html` مباشرة من مدير الملفات يسمح بتجربة بعض الميزات، لكن التثبيت وميزة العمل دون اتصال يحتاجان إلى استضافة HTTPS أو بيئة localhost. هذه الحزمة ليست APK ولا منشورة على Google Play.

## البيانات والخصوصية
البيانات تُحفظ محليًا في LocalStorage على المتصفح/الجهاز؛ لا يوجد حساب أو مزامنة سحابية. مسح بيانات المتصفح قد يحذف السجلات، لذا استخدم زر تصدير البيانات دوريًا. صورة الطعام لا تُرسل إلى أي مكان إلا عند الضغط على تحليل AI بعد ضبط عنوان خادم.


## تشغيل تحليل الصور فعليًا (اختياري، يحتاج مفتاح API واستضافة)
أضفت مجلد المشروع نفسه مع ملف `server.js` لخدمة تحليل جاهزة للتشغيل. لن يعمل التحليل من دون إعداد خادم ومفتاح API صالح لدى مزود الذكاء الاصطناعي.

1. ثبّت Node.js 20 أو أحدث على جهاز/خادم.
2. افتح الطرفية داخل مجلد المشروع ونفّذ `npm install`.
3. اضبط متغير البيئة `OPENAI_API_KEY` على الخادم فقط، ولا تضعه في التطبيق أو تشاركه. يمكنك استخدام `.env.example` كمرجع، لكن لا ترفع ملفًا يحتوي المفتاح إلى GitHub.
4. اضبط `ALLOWED_ORIGIN` على رابط تطبيقك المنشور (HTTPS)؛ في بيئة التطوير المحلية يمكن ضبطه وفق عنوان التطوير.
5. شغّل `npm start`. يصبح المسار `/analyze-food`.
6. في إعدادات التطبيق أدخل عنوان HTTPS الكامل للمسار، مثل `https://your-api.example/analyze-food`.

الخادم يستخدم OpenAI Responses API لإرسال صورة كمدخل بصري، وفق توثيق مدخلات الصور الرسمي: https://platform.openai.com/docs/api-reference/responses
قد تُحتسب تكلفة API حسب حسابك واستخدامك. لا توجد تكلفة API ضمن هذه الحزمة نفسها، ولا أستطيع نشر الخادم أو إنشاء مفتاح API نيابةً عنك من هنا. يجب مراجعة تقدير السعرات قبل اعتماده لأن تقدير الوزن والزيوت والمكونات من الصورة قد يكون غير دقيق.
